# Rust 内存管理详解

Rust 是一门注重安全和性能的系统编程语言。它的内存管理机制非常独特，通过所有权系统、借用和生命周期来保证内存安全，而不需要垃圾回收器。

## 所有权系统

所有权是 Rust 最核心的概念之一。所有权规则：

1. 每个值都有一个所有者
2. 同一时间只能有一个所有者
3. 当所有者离开作用域，值将被丢弃

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1; // s1 的所有权转移给 s2
    // println!("{}", s1); // 这行会报错
    println!("{}", s2); // 这是正确的
}
```

## 借用与引用

Rust 通过引用来实现借用，允许你使用值但不获取其所有权：

- 不可变引用：`&T`
- 可变引用：`&mut T`

借用规则：
- 同一时间，要么存在一个可变引用，要么存在任意数量的不可变引用
- 引用必须总是有效的

## 生命周期

生命周期确保引用的有效性。大多数时候，生命周期是隐式的，由编译器推断。

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

## 智能指针

Rust 提供了多种智能指针：

- `Box<T>`：堆分配
- `Rc<T>`：引用计数
- `Arc<T>`：原子引用计数
- `RefCell<T>`：内部可变性

这些智能指针在不同场景下各有用途，帮助开发者更好地管理内存。
