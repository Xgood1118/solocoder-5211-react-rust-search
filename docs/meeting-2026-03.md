## 技术栈升级

### 后端技术选型

讨论了 Rust 在服务端的应用前景：

- 优势：性能好、内存安全、并发友好
- 风险：学习曲线陡峭、生态相对较小
- 决定：先在搜索服务试点

### 前端技术栈

- React 18 升级
- Vite 构建工具
- TypeScript 全面覆盖

## 性能优化

### 搜索性能目标
